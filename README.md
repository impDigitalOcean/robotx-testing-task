# robotx-testing-task
## Текст задачи
Российская компания решила перевести управление своими клиентами из старой учетной системы в новую, основанную на базе данных MS SQL. 
Программисты сделали выгрузку всех клиентов в XLSX файл. Данные выгружены "как есть".

## Задача. 
Написать программу, которая позволяет: 
1. Импортировать Excel-файл в базу данных, приведя данные к необходимому типу
2. Посмотреть данные из БД в каком-нибудь гриде, отредактировать какое-либо поле и записать изменения в БД.
